# Playground 

The playground is a platform for you to explore the data available.

To use it, 
1. Sign up for an account.
1. Go to [API Keys](/dashboard/api-keys), and create a new API key.
1. Go to [API Playground](https://fntu-api.benapps.workers.dev/), go to any route, and paste in the API key in the `Authorization` field.

You can also try it on the Command Line. Try it out, remember to replace `<API_KEY>` with your actual API key:
```bash
curl -X GET "https://fntu-api.benapps.workers.dev/api/classes" \
-H "Authorization: <API_KEY>"
```
