Tool to scrape data and distill it. 

## Prerequisites
- Have [NodeJS](https://nodejs.org/en/download/), [pnpm](https://pnpm.io/installation), and [Git](https://git-scm.com/downloads) installed.
- Clone the [FNTU](https://github.com/Acrylic125/fntu) repository. Run `git clone git@github.com:Acrylic125/fntu.git` then `cd scraper` and `pnpm i`.

## Running the Scraper
Once cloned, run the following commands to start scraping:
```bash
pnpm run start courses
pnpm run start locations
pnpm run start exams
```

The code can be found [here](https://github.com/Acrylic125/fntu/tree/main/scraper).

## High level overview 
![Scraper Steps](/scraper-steps.png)
1. **Source** the data we want to scrape. See **Data Sources** for more details.
1. **Download** the pages (i.e. **Data Sources**).
1. **Scrape** the data from the pages, and consolidate it. (In JSON format)
1. (Optional) **Transform** the data, and consolidate it. (In JSON format)
1. (Optional) **Insert** the data into a database. (Using Drizzle ORM)

You may modify any of these steps to fit your needs.

## Exams pipeline
Unlike courses and locations, the exam timetable cannot be downloaded in a single request. The form needs to be walked step-by-step to keep its hidden state in sync. The CLI flow (`pnpm run start exams`) is broken into the following scripts under [`scraper/download-exams`](https://github.com/Acrylic125/fntu/tree/main/scraper/download-exams):

    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell colSpan={1}>Download</TableCell>
      <TableCell colSpan={2}>`download-plans.ts`</TableCell>
      <TableCell colSpan={2}>POSTs to `MainSubmit` with `p_opt=1` and saves the HTML page that lists every available exam plan.</TableCell>
    </TableRow>
    <TableRow>
      <TableCell colSpan={1}>Scrape</TableCell>
      <TableCell colSpan={2}>`scrape-plans.ts`</TableCell>
      <TableCell colSpan={2}>Parses the radio inputs (`p_plan_no`) from that HTML to produce `{ planNo, name, type }` for each AY/Semester/Special Term. The CLI prompts you to pick the one matching your selected AY/Sem.</TableCell>
    </TableRow>
    <TableRow>
      <TableCell colSpan={1}>Download</TableCell>
      <TableCell colSpan={2}>`download-exams.ts`</TableCell>
      <TableCell colSpan={2}>POSTs the chosen plan to `query_page`, reads the hidden fields (`academic_session`, `p_exam_yr`, `p_semester`, ...) from the response, then POSTs them to `Get_detail` with all filters blank to download the full timetable HTML.</TableCell>
    </TableRow>
    <TableRow>
      <TableCell colSpan={1}>Scrape</TableCell>
      <TableCell colSpan={2}>`scrape-exams.ts`</TableCell>
      <TableCell colSpan={2}>Walks the timetable tables with cheerio. Rows whose first cell matches `DD Month YYYY` are parsed into `{ date, day, timeHour, timeMinute, courseCode, courseTitle, duration }`. NTU's `9.00 am` / `2 hr 30 min` formats are normalised to ISO date + 24h time + decimal hours. The shape is validated by [`schema.ts`](https://github.com/Acrylic125/fntu/blob/main/scraper/download-exams/schema.ts).</TableCell>
    </TableRow>
    <TableRow>
      <TableCell colSpan={1}>Insert</TableCell>
      <TableCell colSpan={2}>`insert.ts`</TableCell>
      <TableCell colSpan={2}>Looks up `coursesTable` rows for the selected `(ay, semester)` to map `courseCode` → `courseId`, then batch-inserts into `examsTable` (1000 rows per batch). Exam rows whose course is missing for that AY/Sem are skipped with a warning, so you should run `pnpm run start courses` for the same AY/Sem first.</TableCell>
    </TableRow>
  </TableBody>
</Table>

All artifacts are written under `out/data-sources/<year>-<sem>/exams/`:
- `plans.html` / `plans.json` — list of available exam plans.
- `exams-plan-<planNo>.html` — raw timetable HTML for the chosen plan.
- `exams-plan-<planNo>.hidden.json` — the hidden form fields used for the `Get_detail` POST (handy for debugging).
- `exams-plan-<planNo>.json` — the final scraped exam rows that get inserted.

## Tips for Scraping
1. Try to find relevant pages to scrape from.
1. Go into **Inspect Element**, typically under **Inspector** tab, download the HTML and see what data is given. Use GenAI to help you extract the data you need.
1. Go into **Inspect Element**, typically under **Network** tab, see what requests are made to the server.
