Tool to scrape data and distill it. 

The code can be found [here](https://github.com/Acrylic125/fntu/tree/main/scraper).

## High level overview 
![Scraper Steps](/scraper-steps.png)
1. **Source** the data we want to scrape. See **Data Sources** for more details.
1. **Download** the pages (i.e. **Data Sources**).
1. **Scrape** the data from the pages, and consolidate it. (In JSON format)
1. (Optional) **Transform** the data, and consolidate it. (In JSON format)
1. (Optional) **Insert** the data into a database. (Using Drizzle ORM)

You may modify any of these steps to fit your needs.

## Tips for Scraping
1. Try to find relevant pages to scrape from.
1. Go into **Inspect Element**, typically under **Inspector** tab, download the HTML and see what data is given. Use GenAI to help you extract the data you need.
1. Go into **Inspect Element**, typically under **Network** tab, see what requests are made to the server.
