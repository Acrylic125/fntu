# FNTU
Distilling data from NTU to make it easy for you to build and analyze. 

Checkout the [Docs](https://fntu.benapps.dev) for more information.

## Goals
- To make NTU data accessible, to build and analyze.
- To act as a reference for learning.
- Have fun.

## Repository Setup
- `docs` contains the Documentation site.
- `api` contains the playground API.
- `scraper` contains the download, scraping and insertion scripts.

## Contributions
All contributions are welcome, after all, one of the goals is to provide a platform to learn. Currently, there's no format with filing issues.
